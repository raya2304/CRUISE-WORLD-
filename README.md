# Cruise World

Cruise World is a responsive luxury cruise travel website designed to showcase cruise destinations, ships, cabins, experiences, and travel itineraries through an interactive and visually engaging interface.

## Features

* Responsive navigation with mobile menu
* Luxury cruise hero section
* Destination search and category filtering
* Featured cruise ship cards
* Cruise ship details using interactive modals
* Ocean Interior, Ocean View, and Ocean Suite cabin sections
* Onboard experiences including dining, spa, pool, and entertainment
* 7-day Mediterranean cruise itinerary
* Interactive image gallery
* Gallery preview modal
* Dynamic cruise price calculator
* Guest and cabin selection
* Duration-based pricing
* FAQ accordion
* Enquiry form with JavaScript validation
* Toast notifications
* Responsive design for desktop, tablet, and mobile

## Technologies Used

* HTML5
* Tailwind CSS
* JavaScript
* Unsplash Images

JavaScript is used to add interactive features such as:

* Price calculation
* FAQ accordion

## Design

The website uses a luxury-inspired visual style with a combination of:

* Navy blue
* Cream
* Gold
* Dark brown accents

The layout focuses on clean sections, large travel imagery, responsive cards, and simple interactions.

## How to Run

1. Download or clone the repository.
2. Open the project folder.
3. Open `index.html` in a web browser.

No additional installation or backend setup is required.
